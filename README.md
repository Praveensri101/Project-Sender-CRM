# Project Sender CRM

A web-based Customer Relationship Management (CRM) application for managing customer information in one place.

## Features

- Add new customers
- View customer records
- Search customers
- Edit customer details
- Delete customer records
- Dashboard with customer statistics
- Track project value, advance, and balance
- Store customer data in CSV format

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Data Storage
- CSV File

### Libraries
- csv-parser
- json2csv
